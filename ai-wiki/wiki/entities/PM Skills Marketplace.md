# PM Skills Marketplace

> 面向产品经理的AI技能市场，将成熟PM框架编码为结构化引导式工作流，覆盖产品发现、策略、执行、上市全流程

## 简介

PM Skills Marketplace 是一个面向产品经理的AI技能集合平台，核心区别于通用AI工具的地方在于：它不是让AI自由生成文字，而是把经过验证的PM方法论框架（来自Teresa Torres、Marty Cagan、Alberto Savoia等行业权威）转化为AI可执行的结构化工作流。这意味着产品经理使用这些技能时，AI会按照成熟框架一步步引导思考，而非直接给出答案。

平台覆盖产品工作的完整生命周期，从发现阶段的问题验证到上市阶段的市场策略，每个环节都有对应的技能和工作流支撑。这种"框架驱动而非答案驱动"的设计哲学，与单纯让AI写PRD或生成报告的用法有本质区别。

## 关键信息

- **类型**：工具（AI技能集合/插件市场）
- **领域**：产品管理 / AI辅助决策
- **官方网站/地址**：https://github.com/phuryn/pm-skills
- **定价/开源状态**：开源
- **相关概念**：Product Manager Skills、提示词工程、AI产品经理工作流

## 核心特性

### 规模与构成

- **8个插件**：覆盖不同产品工作场景的独立功能模块
- **65个技能**：单一任务的AI引导操作（如用户访谈提纲生成、竞品对比分析）
- **36个链式工作流**：多步骤串联的完整流程（如从问题发现到方案验证的全链路）

### 方法论框架来源

技能背后的PM框架均来自行业权威：

- **Teresa Torres**：持续发现框架（Continuous Discovery），强调通过持续的用户研究来驱动产品决策
- **Marty Cagan**：硅谷产品集团创始人，启发式产品团队方法论，强调 empowered teams
- **Alberto Savoia**：谷歌前工程总监，Pretotyping（预原型）方法论，强调"确保做正确的事"先于"把事情做对"

### 设计哲学

核心理念：不是让AI生成一堆文字，而是将成熟的PM框架编码为结构化的引导式工作流，帮助产品经理做出更好的产品决策。AI扮演的角色是"框架引导者"而非"答案生成者"。

### 工具/模型类实体的必填项

- **安装方式**：从 GitHub 仓库 https://github.com/phuryn/pm-skills 获取，可运行在 Claude Code 等AI Agent上
- **基本用法**：在支持的AI Agent环境中加载技能，通过自然语言指令调用特定工作流
- **适用场景**：产品经理需要在特定工作环节（如用户研究、竞品分析、需求评审）中应用成熟方法论时使用，适合追求"按框架思考"而非"让AI直接出答案"的场景

## 不同素材中的观点

- **2026-05-09-pm-ai-playbook**：这篇素材将PM Skills Marketplace定位为"让产品经理事半功倍"的实用工具，强调其核心价值在于把成熟PM框架编码为结构化工作流而非自由生成，与其他通用AI助手形成差异化。素材同时推荐了另一款同类工具 Product Manager Skills，两者互补而非竞争关系。

## 实用信息

- **快速上手步骤**：1) 访问 GitHub 仓库获取技能包；2) 在 Claude Code 等AI Agent环境中安装；3) 按需调用特定技能或工作流
- **注意事项/避坑指南**：技能的效果取决于用户对PM框架本身的理解，如果对 Teresa Torres 或 Marty Cagan 的方法论不熟悉，建议先了解框架原理再使用对应技能，避免"只走形式不理解意图"
