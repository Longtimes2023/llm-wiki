# 派大星选题法

> 用两个五角星做"赛道 × 兴趣"连连看的爆款选题工程化方法。一次画图产出 25 个可执行选题，解决日更博主"每天不知道发什么"的核心问题。

## 简介

派大星选题法是王富贵儿在《用设计思维做自媒体与变现产品》一文中提出的自创选题方法论，因其形似海绵宝宝中派大星的五角星形状得名。它把自媒体选题从"等灵感"变成了"画图找组合"——画两个五角星，第一个写"赛道关键词"，第二个写"目标人群兴趣"，做连连看就能产出 25 个可执行选题（5 × 5）。

派大星选题法的底层逻辑是：**爆款不在独创而在重新组合**——90% 的"创新"都是基于重新组合（"偷来的艺术最是伟大，艺术来源于生活"）。同样的"瘦肚子"内容，加上"追剧"场景就变成"三个简单动作，一边追剧一边瘦肚子"；同样的"食谱"内容，加上"买衣服"动机就变成"按这个食谱吃，下个月买衣服要买小一码"。组合产生新意，新意带来流量。

这个方法解决了自媒体新手最常见的三个问题：①日更没素材（每天画图就有 25 个选题）；②选题太干（每个选题都自带具体场景和动机）；③选题不接地气（兴趣关键词来自用户生活，不是创作者自嗨）。它是作者总结的三大选题方法之一，被定位为"最适合从零开始日更"的工程化方法（另外两个是低粉爆款对标 + 同行评论区挖问题）。

## 关键信息

- **类型**：选题方法论 / 内容工程化工具
- **核心问题**：自媒体博主如何稳定日更、源源不断产出爆款选题
- **基本结构**：两个五角星 × 5 个关键词 × 连连看 = 25 个组合选题
- **应用平台**：短视频（抖音/快手/视频号）、图文（小红书/公众号/微博）

## 核心特性

### 1. 完整流程：画两个五角星 → 连连看 → 选题成型

派大星选题法的标准操作流程：

**第一步：画第一个五角星 · 赛道关键词**

中间写上你的赛道（例如：减肥健身），五个角写要触发的关键词：
- 瘦小腿
- 瘦肚子
- 食谱
- 健身房
- 快点瘦

**第二步：画第二个五角星 · 目标人群兴趣**

中间写"兴趣"，五个角写目标人群常做的事 / 关心的话题：
- 吃零食
- 追剧
- 谈恋爱
- 旅游
- 买衣服

**第三步：做连连看**

把两个五角星的关键词两两组合：

| 赛道关键词 | 兴趣关键词 | 选题示例 |
|----------|----------|---------|
| 瘦肚子 | 追剧 | 三个简单动作，一边追剧一边瘦肚子 |
| 食谱 | 买衣服 | 按这个食谱吃，下个月买衣服要买小一码才行 |
| 瑜伽 | 谈恋爱 | 大佬为什么都偏爱练瑜伽的女生呢？ |
| 瘦小腿 | 旅游 | 出门旅游不敢穿短裙？睡前 3 分钟瘦小腿 |
| 健身房 | 吃零食 | 健身房后吃这 5 种零食，越吃越瘦 |

5 × 5 = 25 个组合，去掉不合理的，至少能产出 15 个可执行选题。

### 2. 为什么有效：组合 = 用户场景具体化

派大星选题法之所以有效，不是因为"组合数学多"，而是因为它强迫创作者把抽象的"赛道关键词"和具体的"用户场景"绑定起来。

单独的"瘦肚子"是教科书选题，观众路过会觉得"我知道我胖，但我没空"；"一边追剧一边瘦肚子"是场景选题，观众会想"我每天都在追剧，那这个我能做"。区别在于：
- 教科书选题 = 我教你 → 你应该学 → 你大概率不学
- 场景选题 = 你正在做这件事 → 我帮你顺便做另一件事 → 你大概率会试

这与王富贵儿在同一篇文章中提出的"懒惰心理"是完全对应的——人们想要的不仅仅是专业，还要坐享其成、毫不费力地得到。派大星选题法的兴趣五角星部分，本质上是在选题阶段就把"懒惰心理"内置到选题里。

### 3. 不同赛道的派大星模板

#### 案例 1：减肥健身（原文示例）

```
赛道五角星：瘦小腿 / 瘦肚子 / 食谱 / 健身房 / 快点瘦
兴趣五角星：吃零食 / 追剧 / 谈恋爱 / 旅游 / 买衣服
```

#### 案例 2：设计师跨界

```
赛道五角星：海报设计 / 字体排版 / 配色 / Logo / 品牌全案
兴趣五角星：找工作 / 谈薪资 / 接私活 / 自媒体起号 / 学习副业
```

潜在组合：
- 海报设计 + 找工作 = 海报作品集这样改，HR 30 秒就想约你面试
- 配色 + 接私活 = 私活客户最爱的 5 种配色，开口价就能翻倍
- Logo + 自媒体起号 = 头像 Logo 怎么设计，粉丝一眼记住你

#### 案例 3：AI 工具 + 产品经理

```
赛道五角星：需求文档 / 竞品分析 / 用户调研 / Roadmap / 数据分析
兴趣五角星：35 岁危机 / 跳槽 / 升职 / 加薪 / 副业
```

潜在组合：
- 需求文档 + 跳槽 = 用 AI 把 3 年 PRD 输出整理成跳槽作品集
- 用户调研 + 副业 = AI 帮我做用户调研，副业咨询单接到手软
- 竞品分析 + 35 岁危机 = 35 岁 PM 用 AI 重做竞品分析，被前老板挖回去

### 4. 与其他选题方法的协同

派大星选题法不是孤立的，作者把它定位为三大选题方法之一：

| 方法 | 适用阶段 | 优势 | 劣势 |
|------|---------|------|------|
| 低粉爆款对标 | 起号期 | 已经被市场验证的选题，可控性强 | 算法迭代后红利下降，需要持续找新对标 |
| 同行评论区 | 起号 + 成熟期 | 100 个选题 30 分钟出来，全是真实需求 | 需要你的同行账号有足够评论量 |
| 派大星选题法 | 全周期 | 5×5 = 25 个，全部自由组合，不抄不雷同 | 需要你对赛道和用户都有理解 |

另外作者还补充了**情绪选题法**——根据自己被触动的情绪做选题（共鸣、遗憾、可惜），适合做"故事型"内容（如《当初我要是没选择做设计，会不会更好？》）。

### 5. 派大星选题法 vs 小红书 6 步公式

派大星选题法关注"选什么题"，小红书 6 步公式（[[2026-04-29-deepseek-xiaohongshu-formula]]）关注"题选好了怎么写"。两者可以叠加：

```
派大星 → 选题：一边追剧一边瘦肚子的三个动作
   ↓
小红书 6 步公式：
  - 场景定位：周末晚上的追剧时间
  - 目标用户：上班族女性，没时间健身
  - 痛点切入：每天累得只想躺着追剧
  - 价值锚点：3 个动作 + 一集剧 = 一个月瘦 5 斤
  - 行动召唤：保存这条，今晚就开练
  - 情绪共鸣：终于不用为减肥放弃追剧了
```

## 不同素材中的观点

- **[[2026-05-26-woshipm-design-thinking-self-media]]**：王富贵儿首次系统提出"派大星选题法"，把自媒体选题从"等灵感"工程化为"画图做连连看"。文章用减肥健身赛道做完整示例（瘦小腿/瘦肚子/食谱/健身房/快点瘦 × 吃零食/追剧/谈恋爱/旅游/买衣服），给出 3 个组合示例：①追剧+瘦肚子=三个简单动作一边追剧一边瘦肚子 ②食谱+买衣服=按这个食谱吃下个月买衣服要买小一码 ③瑜伽+谈恋爱=大佬为什么都偏爱练瑜伽的女生。文章把派大星选题法定位为"所有赛道谁用谁火"的工程化方法，与"低粉爆款对标""同行评论区挖问题""情绪选题"形成四件套。

## 实用信息

### 操作步骤（30 分钟出 25 个选题）

1. **第 1-5 分钟 · 画赛道五角星**：在纸/白板/Excel 上画第一个五角星，中间写赛道，五个角写赛道里最常被搜索/最容易被关心的 5 个子主题。
2. **第 5-10 分钟 · 画兴趣五角星**：画第二个五角星，中间写"兴趣"，五个角写目标人群每天都在做或经常关心的 5 件事。
3. **第 10-25 分钟 · 做连连看 25 组合**：把两个五角星的关键词两两组合，写出 25 条候选选题，先不评判合理性。
4. **第 25-30 分钟 · 筛选 + 优化**：去掉明显不合理的（比如"健身房+吃零食"想不到合理组合），把剩下的优化成钩子型标题（参考 [[短视频钩子]]）。

### 实操示例：副业赛道

```
赛道五角星（副业）：
- 写作变现
- 拍视频
- 卖知识
- 私域运营
- AI 工具

兴趣五角星（上班族日常）：
- 通勤
- 周末
- 午休
- 加班
- 失眠

连连看选题：
- 通勤 + 写作变现 = 通勤路上一小时月入 3000，我做对了 5 件事
- 周末 + 拍视频 = 周末两天拍够一周内容，0 后期也能日更
- 午休 + AI 工具 = 午休 20 分钟，我用 AI 干完了同事一天的活
- 加班 + 卖知识 = 加班时偷偷做的 PPT 模板，每月卖出 5000
- 失眠 + 私域运营 = 失眠时整理的客户群运营 SOP，第二天涨粉 200
```

### 常见误区

1. **关键词太抽象**：写"专业" / "成长" / "审美"——这些词没法触发观众的具体场景。改写为更具体的动作（"专业" → "面试技巧" / "成长" → "升职涨薪" / "审美" → "搭配技巧"）。
2. **兴趣关键词不是目标用户的兴趣**：写自己的兴趣（设计师爱看的纪录片），不是用户的兴趣（用户更可能在追剧/逛淘宝）。要换位思考：你的目标用户每天 24 小时都在做什么？
3. **组合没有矛盾点 / 反差点**：好的组合自带反差（"加班" vs "卖知识"、"失眠" vs "私域运营"）。如果组合很顺滑、没有反差，钩子就弱。
4. **不做就觉得没用**：派大星选题法的价值在"做"——纸上画一遍 25 个选题比看 100 篇方法论都有用。
5. **每天都做派大星**：不需要。一周做一次 / 一个赛道做一次，攒下来的选题够用 1-2 个月。

### 与 AI 的配合方式

派大星选题法可以让 AI 帮忙做"扩展候选词 + 评估组合合理性"：

```
Prompt 模板：

我在做派大星选题法，赛道是【XX】，目标用户是【XX】。
请帮我做两件事：

1. 给我赛道五角星的 5 个核心关键词，要满足：
   - 覆盖赛道里最常被搜索的子主题
   - 每个关键词可以独立成为一个选题方向

2. 给我目标用户兴趣五角星的 5 个核心关键词，要满足：
   - 是目标用户日常 24 小时内会做的事或会关心的话题
   - 每个关键词都能跟赛道的 5 个关键词产生组合

3. 给出 5 × 5 = 25 个组合的选题候选，并标注：
   - 反差强度（★ ~ ★★★★★）
   - 适合平台（短视频 / 图文 / 直播）
   - 钩子类型（结果型 / 痛点型 / 悬念型 / 冲突型 / 情绪共鸣型）
```
