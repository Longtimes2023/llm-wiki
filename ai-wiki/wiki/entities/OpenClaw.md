# OpenClaw

> 2026 年 3 月 GitHub 全球排名第一的开源软件项目，本质是"连接器"：一端接人的聊天指令入口（飞书等），另一端接大模型能力和各类应用接口，将分散在不同工具和岗位中的工作串成自动运转的流程。

## 简介

OpenClaw 是一款开源的 AI 工作流编排工具，在 2026 年 3 月时登顶 GitHub 全球排名第一。它的核心价值不在于"让 AI 写文章"，而在于**把过去分散在不同工具和岗位中的工作，串成一条可以自动运转的流程**。

与传统的内容生成工具不同，OpenClaw 更接近一个"数字员工管理平台"：用户在飞书等聊天工具发送一句指令，OpenClaw 将其转化为多步骤的 Agent 工作流，调用 DeepSeek、即梦、各平台 API 等，最终输出到目标平台。

典型应用场景：技术博主张子良用 OpenClaw + DeepSeek 将原本需要 5 人团队（编辑、设计、运营、数据分析）的内容运营工作，压缩为一人在飞书发一句话即可驱动的自动化 SOP。

## 核心特性

### 1. 连接器架构
- 输入端：飞书等聊天工具作为指令入口（移动化特性）
- 输出端：DeepSeek、公众号、小红书、即梦/Midjourney 等各类接口
- 核心逻辑：把"人的指令"翻译成"多工具协作的自动化流程"

### 2. 数据驱动选题
- 自动抓取行业热点榜单
- 监控对标账号和竞品内容
- 识别人类直觉会忽略的非显而易见选题机会（案例：发现"OpenClaw 卸载"是第二大热点，反向操作后流量爆发）

### 3. 运营分析闭环
- 定时抓取阅读量、点赞数、评论区关键词
- 生成日报推送到手机
- 数据反馈驱动次日选题策略调整

### 4. 移动化 Agent 调度
- 坐地铁时在飞书发语音："帮我查今天科技圈最火的新闻，结合我的风格写一篇短评，配一张赛博朋克风的图，发到我的小红书草稿箱"
- 出地铁站时活已经干完

## 实用信息

### 安装方式
- 官方原版：GitHub 开源版本（2026 年 3 月全球排名第一）
- 不建议：市面上各种"XXCloud"、"XX龙虾"等套壳版本（含私有模型、价格贵、安全风险高）

### 硬件环境推荐
- **高配版**：Mac 电脑（32G 内存以上），统一内存架构适合本地部署大模型
- **性价比版**：云服务器（Linux 系统），一年几百块，24 小时云端运行
- **系统兼容性**：Mac/Linux 原生支持最好；Windows 也能跑，但在依赖、权限和兼容性上更容易遇到问题

### 配套模型推荐
- 文案创作：DeepSeek（性价比最优，百万 Token 几块钱）
- 配图：即梦（Jimeng）或 Midjourney
- 代码任务：GPT、Claude、DeepSeek 均可

### 平台风控策略（2026 年 3 月实测）
| 平台 | 风控程度 | 推荐策略 |
|------|---------|---------|
| 小红书 | 高（正在收紧） | 小号测试 + 控制频率（一天一更）+ 人工复核 |
| 微信公众号 | 较宽松 | 自动写入草稿箱 + 人工定时发送（半自动） |
| 视频号/抖音 | 未知 | 谨慎操作，仍在探索 |

### 注意事项
- 合规审核 Agent 不能省：AI 有时会生成敏感词或夸大标题，直接发布可能导致封号
- 不建议使用来路不明的魔改版：存在安全风险和价格陷阱
- 官方 Skill 市场的第三方 Skill 需自行评估安全性

### 关于 OpenClaw 在 To B 销售运营中的应用
来源：[[2026-05-26-woshipm-to-b-sales-ops-ai-roadmap]]
> 疏桐to b运营在 To B 销售运营 AI 提效路线图中将 OpenClaw 列为流程自动化场景的推荐工具——"Openclaw+AI实现跨系统自动操作，减少重复劳动"，验证了 OpenClaw 的应用场景从内容运营向企业销售运营的横向扩展。
