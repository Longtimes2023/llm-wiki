# 能力强的人都会建立SOP

> 工作能力强的人会把身边重复发生的事化解为 SOP，本文给出四个可立即落地的人本 SOP：执行用 PDCA、复盘用 5问、沟通用 SCQA、时间管理用重要紧急四象限——这正是与 [[Skill]]（写给 AI 的 SOP）相对的"写给人的 SOP"。

## 核心观点

1. **能力强的人靠把问题 SOP 化提升效率**：作者开篇直接给出结论——工作能力强的人会把身边的问题化解为 SOP，把复杂问题简单化、把重复工作流程化。这个观点的关键是把"靠状态干活"升级为"靠流程干活"，差别在于 SOP 让结果不再依赖每次的个人状态和临场发挥。
2. **执行的 SOP 是 PDCA，让事情"凡事有交代、件件有着落、事事有回音"**：plan（先把目标和核心计划想清楚）→ do（执行力是优秀品质，不到结果不罢休）→ check（检查执行是否到位、有没有走偏，走偏立刻调头）→ act（针对发现的问题找办法，解决不了就求助他人）。PDCA 把"开了头没下文"的执行失效问题闭环了。
3. **复盘的 SOP 是"多问几个为什么"，挖到本质才能从根源解决问题**：作者把复盘的方法压成一句——不断深挖背后的真正原因。这与丰田 5 Why 的思路一致：越深挖越能跳出表面归因（人不努力、时间不够），找到结构性原因，否则下一次会用相同方式失败。
4. **沟通的 SOP 是 SCQA，解决"汇报很多却抓不住重点"的问题**：情景（描述背景和现状引入话题）→ 冲突（这个背景下有什么冲突，突出严重性）→ 问题（抛出痛点引发对方思考）→ 答案（针对问题给解决方法）。这个顺序的关键是用冲突制造注意力、用问题制造好奇、再给答案——而不是上来就堆细节让领导自己提炼。
5. **时间管理的 SOP 是重要紧急四象限，且四个象限有差异化策略**：重要不紧急——重点做（这是真正的复利区）；重要紧急——优先处理但要尽量减少（说明上游规划有问题）；不重要紧急——委托他人做；不重要不紧急——不做。最容易出问题的是把"不重要紧急"当成自己必须做的事，把"重要不紧急"无限延期。

### 操作步骤

**执行 SOP — PDCA 四步**：
1. **Plan（计划）**：把目标计划想清楚，通盘思考后明确"最重要的事情是什么、核心目标是什么"
2. **Do（执行）**：按规划行动，执行力是优秀的人的共同品质——"不到结果，誓不罢休"
3. **Check（检查）**：执行后检查是否到位、实际完成情况、过程中有无问题、是否走偏；走偏要及时调头
4. **Act（处理）**：针对发现的问题找解决办法，自己解决不了的求助他人

**复盘 SOP — 多问几个为什么**：
- 对任意问题反复追问"为什么"，挖到背后的真正原因
- 挖得越深，越能发现本质，才能从根源解决问题

**沟通 SOP — SCQA 四步**：
1. **S（Situation / 情景）**：描述背景和现状，引入话题
2. **C（Conflict / 冲突）**：在这个背景下有哪些冲突，突出问题的严重性
3. **Q（Question / 问题）**：提出问题，抛出痛点，引发对方思考和探究
4. **A（Answer / 答案）**：针对这些问题，给出好的解决方法

**时间管理 SOP — 重要紧急四象限策略**：

| 象限 | 处理策略 | 说明 |
|------|---------|------|
| 重要 + 不紧急 | **重点做** | 真正能积累复利的事 |
| 重要 + 紧急 | **优先处理，但尽量减少** | 多说明上游规划失效 |
| 不重要 + 紧急 | **委托他人做** | 不要让别人的紧急侵占自己的时间 |
| 不重要 + 不紧急 | **不做** | 直接放弃，不进 To Do List |
