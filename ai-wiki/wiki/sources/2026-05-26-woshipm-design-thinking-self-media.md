# 用设计思维做自媒体与变现产品

> 作者：王富贵儿本人 ｜ 站点：人人都是产品经理 ｜ 发布：2026-04-21 ｜ 字数：约 19500

## 基本信息

- **类型**：自媒体方法论长文
- **领域**：自媒体运营 / 内容创作 / 短视频 / 个人 IP
- **作者背景**：品牌设计师转行自媒体编导，曾帮百万粉丝博主做脚本策划、人设定位、转型与拍剪指导，最高点赞 289.6w，播放过千万
- **核心命题**：自媒体的成功秘诀不在独创而在迭代——用设计思维（拆解元素 + 重新组合）做内容、起号和变现

## 核心观点

1. **自媒体是迭代的艺术，90% 的"创新"都是重新组合**。2022 年的爆款选题套用新场景/人物/梗，今天做出来依然会爆。永远爆款的母题只有 8 个：原生家庭、情感、职场、人生热爱、选择、爱与自由与死亡与孤独、自我救赎、赚钱与人际关系。借鉴爆款不要抄内容，而是看核心论点、论据结构和金字塔思维。

2. **起号最大的坑是养号——养号是骗局**。账号有两个标签：创作者内容标签（你发的内容定位）和用户标签（你看的内容）。互相关注、互相评论、刷同行视频不会增加账号权重，反而被识别为作弊。起号三步走是：①对标 1 万粉以下低粉爆款 ②三段式保留结构（开头钩子不动 + 替换案例 + 更换金句）③模仿语气断句停顿。

3. **短视频要的是情绪和体验，知识只是营销自己的点缀**。这是全文最重要的判断之一。太专业的内容只能吸引同行白嫖；普通用户要的是"获得感、惊喜感、表达力、感染力"（抖音公开标准）。"活人感"——立体的人的感觉——比专业知识更重要。

4. **粉丝关注你只有 4 个动机：真厉害、真有用、真喜欢、真懂我**。真厉害靠时间线+狠（每天 5 点起一天学 16 小时）；真有用靠"在别人愿意接受的情况下提供有效帮助"（不是"为你好"）；真喜欢是从认识到认可、从信息到人设；真懂我是说出粉丝困惑、共振粉丝情绪。

5. **爆款的秘密 = 精准命中骨子里的人性弱点**。4 个永恒弱点 = 懒惰（"每天 5 分钟会喘气就会做"）+ 害怕（女人怕丑、孩子怕笨、老人怕死、男人怕不行——四个永不过时的变现赛道）+ 从众跟风（《乌合之众》：一个人没有信念，一群人有共同信念）+ 厌恶失去（比起得到更怕失去）。

6. **"派大星选题法"——两个五角星连连看**：第一个五角星写赛道五个触发关键词，第二个写目标人群五个兴趣点，做连连看就有 25 个选题。例如"减肥健身 × 追剧 = 一边追剧一边瘦肚子的三个动作"。配合"低粉爆款+评论区+情绪选题"三大方法，可日更不断。

7. **"框架效应"是爆款话术的核武器**。同样讲环境保护，框架一"绿色经济创造就业机会"塑造正面形象，框架二"气候危机生态灾难"激起恐惧。同一选题用不同框架表述，引发不同情感反应，激活不同受众。"女性上桌""帮弱势群体发声"等爆款都是框架效应的应用。

8. **图文是洗稿重灾区，必须做视频**。一个图文工作室一天能发 1000 个账号，门槛越低越难做。即使小红书是图文起家，现在涨粉和观看率最多的也是短视频。视频露脸至少还能申诉原创。

9. **设计思维 = 拆解元素 + 重新组合 + 找主体**。自媒体制作 = 专业 + 情绪 + 人设。出镜是对抗同质化的方法之一（你的脸就是原创）。人物关系决定语气情绪——同样讲"自洽"，对女儿/对对象/对长辈/对学生说，效果完全不同。

10. **变现需要提前准备产品与商业定位**。教设计的要准备：咨询服务、陪拍服务、卖资料、卖课。视频不只是为了曝光，是为了让产品被需要。一开始就有变现路径，才能形成"做内容 → 开单 → 更有能量 → 做更多内容"的正向循环。

## 实操内容保留

### 起号三步走（防养号陷阱）

```
第一步 · 对标低粉爆款
- 重点是低粉（1 万粉以下），其次才是爆款
- 图文：1000 赞算小爆款
- 视频：3-5k 赞算不错爆款

第二步 · 三段式保留结构（不是抄）
- 开头钩子：完播率保障，尽量不动
- 中间内容：他讲猫你就讲狗，同类替换、格式不变
- 结尾金句：网上搜相同意思的金句进行替换

第三步 · 模仿语气断句
- 跟着对标账号的视频读 5 遍
- 或把朋友的照片贴在提词器旁边（建立"对象感"）
```

### 派大星选题法（5x5 连连看）

```
第一个五角星 · 赛道关键词（以减肥健身为例）
    瘦小腿
  /        \
食谱        瘦肚子
  \        /
   健身房-快点瘦

第二个五角星 · 目标人群兴趣
    吃零食
  /        \
买衣服      追剧
  \        /
   旅游-谈恋爱

连连看示例：
- 追剧 + 瘦肚子 = "三个简单动作，一边追剧一边瘦肚子"
- 食谱 + 买衣服 = "按这个食谱吃，下个月买衣服要买小一码"
- 瑜伽 + 谈恋爱 = "大佬为什么都偏爱练瑜伽的女生呢？"
```

### 爆款文案循环体系（问题+难点+需求三方案）

```
格式 = 提问 + 难点 + 需求

示例 1：
你做自媒体为什么没有流量（提问）？
因为你的口播表情不自然（难点），
两个方法就能让你毫不费力的做到（需求）。

示例 2：
你做自媒体为什么不涨粉（提问）？
因为你的口播表情不自然（难点），
你一定要学会的三天速成法（需求）。
```

排列组合数量 = 问题数 × 难点数 × 需求数，资料越多组合越多。

### 不同赛道冲突设计模板

| 赛道 | 冲突核心 | 钩子示例 |
|------|---------|---------|
| 宝妈/教育 | 妈妈和孩子写作业 | 别再逼孩子刷题了，全班倒数逆袭前十，靠的根本不是死读书 |
| 美妆护肤 | 高价 vs 低价 | 花 3000 买的贵妇霜，竟不如 50 块的它 |
| 减肥健身 | 努力 vs 效果差 | 每天狂练两小时，还瘦不下来，因为你一开始就练错了 |
| 美食餐饮 | 米其林 vs 家常 | 米其林大厨都在夸的秘方，在家 5 分钟就能搞定 |
| 职场/培训 | 加班 vs 升职 | 熬夜加班的人都没升职，准时下班的却成了总监 |
| 母婴 | 进口 vs 国产 | 进口奶粉真的好吗，亲身经历告诉你，喂错比饿着更可怕 |

### 人物关系切换法（同一选题 4 种表达）

主题：教自洽

- **对女儿**：女儿呀，你知道这辈子最舒服的状态是什么样的吗？像你现在这样的，就是最舒服的，很自洽……
- **对对象**：诶，十一你知道怎么才能做到自洽吗？
- **对长辈**：吴姐，你对自洽有什么看法吗？想跟你请教一下，我最近有点迷茫……
- **对学生**：同学们，自洽是我们唯一要追求的终极目的，没有什么比这更理想的理想了……

### 4 个人性弱点变现公式

| 弱点 | 公式逻辑 | 文案示例 |
|------|---------|---------|
| 懒惰 | "毫不费力"+"快"+"傻瓜化" | 每天 5 分钟，10 天拥有马甲线，会喘气就会做的三个动作 |
| 害怕 | 女人怕丑/孩子怕笨/老人怕死/男人怕不行 | 从笨小孩到年级前十，我们只做对了一件事 |
| 从众 | "XX 都在用"+"被追问 N 次" | 财务自由的女生都在培养的 6 个习惯 |
| 厌恶失去 | "因为 X，导致少赚/多胖" | 因为我做错了 3 件事，减肥失败还胖了 5 斤 |

## 原文精彩摘录

> "做过设计的人应该都知道，每年都会有很多设计形式，风格……现在的设计迭代基本都是吃老本，但都在老本身上进行一些'捏造'，创新组合。我们都知道，偷来的艺术最是伟大，艺术来源于生活嘛。90%的创新都是基于重新组合。所以呢，只要这些风格形式符合市场需求或者高出1%，那就是可以挣钱的。自媒体也是迭代的艺术。"

> "短视频要的是情绪和体验，和知识无关，知识只是营销你自己的一个点缀。"

> "爆款从来都不是拼设备、拼技术，是拼你对人间百态的敏感度，把生活里那些憋屈的、感动的、离谱的，用冲突的形式去放大。当你成为了矛盾的解决者，你就掌握了流量的钥匙。"

> "你怕的不是露脸，而是觉得自己做不成。如果现在你有 500 万粉丝，你还会怕熟人刷到你吗？不但不怕，你都恨不得让全天下都知道你有 500 万粉丝。"

> "重点不是内容，是你如何让这些知识链接起来，形成自己的知识库。就像做设计嘛，你做海报肯定得有1234的步骤……知道该怎么链接开头、中间、结尾、售后、复盘，这才是真正学会了并且会用了。"

> "信息爆炸的时代，最重要的不是信息了，是如何深耕一方面，做到极致。低头走路的时候，也要抬头看路，方便调整方向。定了大概的目标，就可以去执行了，不用等很久。执行才会有答案。"

> "愿意沉下心执行的人，肯定不是为了做一个'网红'，他是要成为'在自己领域里，不可替代的权威'。"

## 适用读者

- **自媒体新手**（最适合）：从 0 起号到第一波粉丝，避免养号陷阱、上手三段式仿写、用派大星选题法日更
- **百粉/千粉博主**：从"专业 + 干货"破局，加入活人感、人设、情绪、人性弱点设计

- **AI 时代的内容创作者**：人工选题工程化 + 活人感不可被 AI 替代，是与 AI 内容生产工具配合的人类核心能力
