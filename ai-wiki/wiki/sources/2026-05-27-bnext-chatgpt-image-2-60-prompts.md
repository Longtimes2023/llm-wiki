2. **提示词结构呈现"双层骨架"——属性描述 + 视觉关键词**：每个提示词由"主题画面叙述（中文自然语言）"+"风格关键词列表（中英混合）"两层组成，例如旅游海报的关键词层 `premium Korean travel magazine collage style, layered composition, soft shadow, bright natural lighting, aesthetic editorial layout, ultra detailed, cozy travel atmosphere`，结构与 [[2026-05-10-gpt-image-2-prompt-templates]] 的 Prompt-as-Code Schema 一致，但本文采用自然语言版本而非 JSON。

3. **"照片风格转换类"通过约束条件锁定人物一致性**：22 组照片风格转换提示词普遍包含"保留原本臉部五官、髮型、表情、姿勢"这一锁定指令，配合"不要重新设计角色，也不要改变人物风格"的负向约束，解决了 Image 2 在人物风格化时的角色漂移问题——这正是 [[GPT Image 2]] 在 [[2026-05-10-gpt-image-2-prompt-templates]] 中被诟病的"人像细节弱"问题的工程化绕过方案。

4. **"模板填空"模式让单条提示词支持无限变体**：编织小人气象图、扭蛋包装风、F1/NBA/CPBL 现场照、偶像打歌 FanCam 等提示词都采用「__」「【车队名称】」「【TEAM_NAME】」「【YOUR_NAME】」式占位符，用户填入城市/车队/球队名/艺名即可复用；这种"提示词模板"思路与 [[提示词工程]] 中"小红书 6 步公式"的占位符设计同源，但视觉场景的占位符更复杂（含多个景点 + 美食 + 配色 + 视觉风格关键词）。

5. **直式 9:16 海报构图是 ChatGPT Image 2.0 在移动端时代的核心交付物**：「釜山 4 天 3 夜旅游海报」「编织小人气象图」「Y2K 四格大头贴」「大头照手机桌布」等高频场景统一指定 9:16 / 直式构图，与之前 [[2026-05-09-codex-visual-style-ppt]] 主导的 16:9 横式 PPT 路线形成互补；移动端社群（IG/小红书/朋友圈/LINE）已成为 Image 2 的主要消费场景。

6. **"上传照片 + 提示词 = 风格转换"是 ChatGPT Image 2.0 的杀手级用法**：照片风格转换类 22 组全部基于「我提供的照片 / 这张图片」做风格化处理，单张照片可通过不同提示词变成蜡笔画 / 塔罗牌 / NBA 场边照 / Y2K 大头贴 / 日本极道千金等差异极大的输出，使得"一张自拍照变 100 种风格"成为 IG 社群内容生产新范式。

### Prompt 模板

下列为本文中具有"模板填空"结构、可批量复用的高价值 Prompt：

**1. 品牌商业策略信息图表（适合替换餐饮品类）**
```
请设计一张【自行填入餐饮品牌】商业策略信息图表，整体风格结合国际顾问公司提案美学与精品餐饮品牌视觉。
画面内容包含品牌定位、顾客旅程、营运优化、数位行销策略、会员经营、品牌成长机会、外送平台拓展、社群媒体经营、顾客留存策略与未来展店规划。
以高级信息图表方式呈现，包括策略地图、KPI 仪表板、时间轴规划、心智图、数据分析图表、商业流程图与品牌成长路径。
视觉风格：米白色背景、深酒红与香槟金点缀、精品级字体设计、现代杂志编排、整齐网格系统、高级留白感、电影级光影、简约高端商业美学。
高细节、干净构图、现代商业信息图表风格、精品级版面设计、国际品牌提案感、高解析度、8K、现代 UI/UX 视觉风格。
```

**2. 釜山 4 天 3 夜旅游杂志拼贴风海报（三步任务结构：行程→文章→海报提示词）**
原文采用 Step 1（输出行程表）→ Step 2（改写为杂志风文章）→ Step 3（生成海报提示词）的三阶段任务拆解，海报关键词：
```
premium Korean travel magazine collage style, layered composition, soft shadow,
bright natural lighting, aesthetic editorial layout, ultra detailed, cozy travel atmosphere
```
配色：白色底＋海洋蓝＋奶油色＋珊瑚橘点缀；比例：9:16 直式海报。

主题：＿＿＿＿＿编织小人气象图

查询后，将天气信息放入中央气象信息牌中。
风格：编织／钩针／毛线／立体玩偶风／可爱疗愈／色彩温暖／微缩模型感
景点元素：代表景点 1~5（填空）
美食元素：在地美食 1~4（填空）
生成风格关键字：
crochet art style, amigurumi, knitted texture, yarn city, handcrafted miniature world,

cinematic lighting, premium editorial illustration, travel magazine style, layered composition,

**4. 冲破手机屏幕（人物突破社群贴文界面）**
```
创建一个高度拟真、具电影感的场景：我正从自己的社群贴文中走进现实世界。
将我置于一支智能手机屏幕中，画面显示一个照片分享型社群贴文界面，并让我从屏幕中突破出来。
人物姿势需重新设计为动态行走中，一脚向前跨出，并使用强烈 3D 透视前缩效果（foreshortening）。
社群界面需为原创设计（不可模仿任何品牌）：上方标题列、个人头像与使用者名称【填入自己的社群帐号】、
中央圆角贴文图片区块、下方互动图示（按赞 / 留言 / 分享 / 收藏）、底部导览列。
在人物突破屏幕的接触点加入特效：玻璃破裂碎片（具光线折射）、向外喷散的数位像素碎片、
前景手脚带有动态模糊拖影、屏幕边界带有微微发光的数位残影效果。
构图为 4:5 直式（1080×1350），画面完整不裁切。
```

**5. Q 版 3D 小人风（迷你分身 + 韩文情绪标题）**
原文 10 节点结构化提示词的核心要点：
- ①人物处理：原始人物必须去背使用，臉部姿势不可更动
- ②迷你角色生成：3~7 个手掌大小的 SD 角色，臉部 / 髮型 / 服装特征完整保留
- ③动作：每个迷你角色必须在动作中（跳跃 / 揮手 / 模仿 / 坐物品 / 爬肩膀），禁止静止角色
- ⑤标题生成：分析图片氛围自动生成简短感性的"韩文标题"，2~5 个单词，避免过于流行语
- ⑦塗鸦元素：箭头 / 圆圈 / 星星 / 爱心 / 虚线，约 3~6 个
- ⑩禁止事项：禁止更动臉部 / 避免角色看起来像分离存在 / 禁止游戏 UI 风格 / 避免卡片新闻风格

**6. F1/NBA/CPBL 现场照模板共用骨架**（赛事现场照通用结构）
```
根据我提供给你的照片，生成一张高解析度、电影级写实风格图片，场景位于【车队/球队名称】现场。
人物穿搭：【车队/球队元素】的日常穿搭，风格自然低调，
画面下方加入真实感转播信息介面：比分 / 局数 / 球员缩写 / DRS 等
UI 为原创科技感设计，不直接复制真实官方转播画面。
攝影设定：转播长焦镜头、浅景深、真实赛事灯光、自然皮肤纹理、8K 超高细节、超写实风格
16:9 画面比例。
```

### 操作步骤

**「上传照片 + 风格转换」标准 SOP**：
1. 上传一张原始照片（自拍 / 风景 / 商品均可）
2. 在提示词开头明确"以这张照片为基础 / 根据我提供的照片"
3. 加入锁定条款："保留人物原本的臉部五官、髮型、表情、姿势 / 不要重新设计角色"
4. 描述目标风格（蜡笔 / 塔罗牌 / 像素 / NBA 场边等）
5. 列出风格关键词（中英混合）
6. 加入负面提示词（避免恐怖谷、避免比例失控、避免低解析度）
7. 指定输出比例（IG 帖文 1:1 / 手机桌布 9:16 / 横幅 16:9）

**模板填空 SOP**（针对编织气象图 / 扭蛋风 / 赛事现场等含占位符模板）：
1. 复制完整模板
2. 替换 `_____` / `【...】` 占位符（城市 / 球队 / 角色等）
3. 保留风格关键字列表不动
4. 保留负面提示词不动
5. 一次性提交给 ChatGPT Image 2.0
