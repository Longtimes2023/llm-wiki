# 50个常用爆款短视频钩子开头模版

## 核心观点

1. **钩子不是创意而是"套路"**：爆款短视频开头不是靠灵感，而是靠可复制的公式化结构。50个钩子模板的底层逻辑是"精准套路触发用户停留欲"，每个公式都有固定结构（【占位符】+【占位符】），创作者只需填入自己的内容即可。
2. **五大钩子类型覆盖不同心理触发机制**：结果型（展示成就引发好奇"怎么做到的"）、痛点型（戳痛点制造"说的就是我"的认同）、悬念型（说一半藏一半制造信息缺口）、冲突型（反常识颠覆认知制造"哎？"反应）、情绪共鸣型（先共情再输出方法）。
3. **反差是所有钩子的核心引擎**：无论是"月薪5000存5万"的数字反差、"从社恐到销冠"的状态反差、"越努力越穷"的认知反差，还是"我不是名校毕业但我进了大厂"的身份反差，反差越大，停留概率越高。
4. **3-5个模板反复练优于50个全试**：作者明确建议不需要全部使用，选3-5个最适合自己赛道的模板反复打磨，比每个都浅尝辄止更有效。这体现的是"少即是多"的复利思维。
5. **钩子的本质是用户心理的精准操控**：50个模板背后的心理学原理包括——好奇心缺口（悬念型）、损失厌恶（痛点型）、社会认同（普通人+不普通结果）、认知失调（冲突型）、情感共鸣（情绪型）。理解原理比背诵公式更重要。

### Prompt 模板

**结果型钩子公式（10个）**：

1. 用了【时间】，我做到了【具体结果】 → 例："用了3个月，我还清了20万债务"
2. 月薪【低数字】，一年存了【高数字】 → 例："月薪5000，一年存了5万"
3. 从【差状态】到【好状态】，我只做了这一件事 → 例："从社恐到销冠，我只改了这一点"
4. 以前我【坏结果】，现在我【好结果】 → 例："以前我熬夜到3点睡不着，现在10分钟入睡"
5. 只花了【低价】，拿到了【高价值】 → 例："只花了50块，我把出租屋改成了ins风"
6. 我一个【普通人】，是怎么【不普通结果】的 → 例："我一个普通上班族，是怎么3个月涨粉5万的"
7. 【短时间】内，我发生了【大变化】 → 例："30天内，我的皮肤从烂脸到素颜出门"
8. 我拒绝了【诱惑】，换来了【好结果】 → 例："我拒绝了月薪3万的offer，现在赚得更多"
9. 没想到，【一个简单动作】让我【好结果】 → 例："没想到，每天早起30分钟，我一年读了50本书"
10. 所有人都说【不可能】，但我【做到了】 → 例："所有人都说我做不起来，现在我有20万粉"

**痛点型钩子公式（10个）**：

11. 你是不是也【痛点场景】 → 例："你是不是也这样，每天忙得要死，却什么都没干？"
12. 我知道你【痛点】，因为我也是这样 → 例："我知道你不敢跟领导提加薪，因为我也不敢"
13. 别再【错误做法】了 → 例："别再熬夜了，真的会猝死"
14. 90%的人都不知道，【真相】 → 例："90%的人敷面膜都敷错了"
15. 你有没有过【具体场景】 → 例："你有没有过，加班到凌晨，地铁停了，打车舍不得？"
16. 【人群】最怕的【数字】件事 → 例："职场新人最怕的3件事"
17. 为什么你【努力做某事】，还是【坏结果】 → 例："为什么你每天健身，还是瘦不下来？"
18. 别等到【坏结果】，才开始【好行为】 → 例："别等到牙疼，才想起来刷牙"
19. 你不是【表面问题】，你是【深层问题】 → 例："你不是懒，你是能量太低了"
20. 我踩过【数字】个坑，你别踩了 → 例："装修我踩过8个坑，你别踩了"

**悬念型钩子公式（10个）**：

21. 我发现了【领域】的一个秘密 → 例："我发现了小红书涨粉的一个秘密"
22. 千万不要【常见行为】，尤其是【人群】 → 例："千万不要在晚上做决定，尤其是敏感的人"
23. 我只做了【简单动作】，但结果【出乎意料】 → 例："我只改了标题的一个字，播放量翻了10倍"
24. 如果你【不做某事】，就会【坏结果】 → 例："如果你还在用这种方式存钱，你会越存越穷"
25. 那天我做了个决定，然后一切都变了 → 例："那天我裸辞了，然后一切都变了"
26. 我不敢相信，【意外结果】竟然发生了 → 例："我不敢相信，一个月的改变这么大"
27. 这就是为什么【现象】会发生 → 例："这就是为什么你越努力越穷"
28. 我花了【时间】，才明白【道理】 → 例："我花了3年，才明白工作不是越努力越好"
29. 一句话说透【复杂问题】 → 例："一句话说透怎么跟领导提加薪"
30. 听劝，【一个建议】 → 例："听劝，别在简历上写'熟练使用Office'"

**冲突型钩子公式（10个）**：

31. 越【A】，越【反常识的B】 → 例："越努力，越贫穷"
32. 别再信【普遍认知】了 → 例："别再信'早起改变人生'了"
33. 谁说【A】就要【B】 → 例："谁说30岁就要结婚？"
34. 我劝你【反常识建议】 → 例："我劝你别和同事做朋友"
35. 真正的【A】，不是【B】，是【C】 → 例："真正的自律，不是早起，是不想做的事也能做"
36. 【短时间】搞定【别人长时间】的事 → 例："10分钟搞定别人3小时的PPT"
37. 废掉一个人最好的方式，是【行为】 → 例："废掉一个人最好的方式，是让他忙到没时间成长"
38. 【A】和【B】的差距，不是【表面】，是【本质】 → 例："你和学霸的差距，不是智商，是方法"
39. 我不【常规优点】，但我【做到了】 → 例："我不是名校毕业，但我进了大厂"
40. 你以为【错误认知】，其实【真相】 → 例："你以为存钱是靠省，其实靠赚"

**情绪共鸣型钩子公式（10个）**：

41. 只有【人群】才懂，【感受】 → 例："只有职场妈妈才懂，下班回家还要'上晚班'的感觉"
42. 那一刻我破防了，因为【事件】 → 例："看到我妈的白头发，那一刻我破防了"
43. 说实话，【真实想法】 → 例："说实话，我不想结婚"
44. 如果你也【经历】，抱抱你 → 例："如果你也在深夜一个人哭过，抱抱你"
45. 我真的受够了【烦心事】 → 例："我真的受够了无效社交"
46. 这件事我想了很久，今天终于决定说出来 → 例："裸辞这件事我想了很久，今天终于决定了"
47. 我后悔没有早点知道【道理】 → 例："我后悔没有早点知道，原来赚钱可以这么简单"
48. 如果你现在【状态】，请一定看完 → 例："如果你现在也很迷茫，请一定看完"
49. 我不怕【A】，我怕【B】 → 例："我不怕加班，我怕加班没有意义"
50. 今天我想说点真心话，关于【主题】 → 例："今天我想说点真心话，关于做自媒体"
